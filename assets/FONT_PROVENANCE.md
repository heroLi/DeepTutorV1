# Bundled font provenance

XiaoBuLearningSansSC.ttf is a static weight-500 derivative of the original project bundled NotoSansSC.ttf, generated with fontTools. All original glyphs, glyph order and Unicode cmap are preserved; the variable weight axis is removed. The renderer previously selected weight 500, and now loads this static face.

The derivative uses the new family name XiaoBu Learning Sans SC. It remains licensed under the SIL Open Font License 1.1 in OFL.txt, including the original copyright and attribution. The font is not sold separately. Original source font SHA-256: a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da

The static artifact fits the publishing connector request limit; it is not a reduced-character subset. The original variable font remains unchanged in the development source copy.
