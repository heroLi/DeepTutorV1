## 连接问题与可重复启动
命令环境和桌面终端显示同一主机名，目录也相同，因此未证实是网络环境隔离。此前命令工具启动的 HTTP 进程未持续存活，浏览器报连接拒绝；同桌面终端前台启动服务后 Chromium 成功连接。桌面终端不包含 Node PATH 时，使用已安装 Node 的绝对路径启动 `dev/parent-flow-preview.js`。普通环境可使用 `npm run dev`。保持终端开启，访问打印出的回环地址。端口每次可能不同，本地记录按 origin 隔离，不是丢失或云同步。

## 实际交互通过
- 数学：首次选 3 错误 → 两步引导 → 原题选 4 正确 → 同类题选 4 错误。完成页及家长小结显示“先复看示范，再试一小步”，两步示范可展开。
- 语文：首次“小”、同类题“窄”正确，完成页记录两次不同作答与保留核查提示。
- 英语：首次 a、同类题 an 正确，记录与支持提示正确。
- 数学提前复习：首次“我还不会” → 两步引导 → 原题 3 正确。标注“帮助后正确”，不算独立掌握；原复习日期 11 月 17 日未被提前作答改变。
- 家长小结：3 轮练习、1 轮复习；练习首次 2/3、原题再试 1/1、同类题 2/3，复习首次 0/1、再试 1/1，引导 4/4，原始错误 3 条。
- 刷新保留记录，切至空档案 B 不出现 A 的记录，切回 A 恢复。清除确认框取消未删除。浏览器前进/后退最终页面与路由一致。
- Chromium 桌面 1180 CSS px、窄屏 400 CSS px（500 px 窗口 + 125% 缩放）和 766 CSS px：所检查的家长小结与支持卡无横向溢出，导航换行、文字与卡片可读；窄屏可滚动访问支持卡，766 px 可展开示范。
