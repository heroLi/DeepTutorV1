# 离线模拟模型安全契约

## 当前交付是什么

这是可运行的 **单进程、内存中、离线契约模拟器**，不是已部署后端，也不是真实 DeepSeek 接入。`server-sim/service.js` 没有 HTTP 监听、网络调用、API 地址、密钥或供应商 SDK。默认 adapter 只返回预先限定的合成题答案。测试中的 adapter 注入仅供可信开发者模拟失败，不是公开插件入口。

浏览器静态体验与此模块是两个独立层次：浏览器直接运行题库和规则提示，不通过本模块请求模型。前端的档案 A/B 仅是本机记录分组，不是登录身份或访问控制。当前浏览器没有真实费用控制；即使以后加入预算/次数提醒，客户端提醒也不能保护真实账户费用。本模块通过测试证明其单进程契约行为，不代表浏览器获得了可信服务端预算限制。

运行：`node --test tests/server-sim.test.js`，或项目根目录 `npm test`。

## 请求与身份边界

`createSimulator()` 返回 `request(trustedContext, request, {signal})` 和只读 `snapshot()`。

- `trustedContext` 必须含 `authenticated: true` 和 `userId`。这只是**可信测试注入**，不是认证技术；绝不能从客户端 JSON 或 URL 直接构造它。
- profile 所有权由初始化时可信 `owners` 映射快照决定，不相信请求中的自报 owner。默认仅有虚构的 `fixture-user-a/b` 与 `fixture-profile-a/b`。
- 请求必须且只能包含 `requestId, profileId, questionId, choiceId`。禁止题文、姓名、年龄、录音、图片、聊天记录、自由文本或 key 字段。对象 getter、未知字段和原型特殊载荷也拒绝。
- questionId 仅允许服务端固定目录中的确切字符串。当前目录是九道合成平均分题：`practice:math:0/1`、`test:math:0..3`、新闭环的 `loop:math:0..2`。后者分别是 12÷3、20÷4、18÷6；测试与前端 loopBank 核对题意及全部选项。新闭环语文/英语仍由浏览器有限规则处理，模拟服务故意不支持其请求。不存在的题不猜测、不换模型、不 fallback。
- choiceId 为选项索引字符串 `0` 至 `3`，不是自由答案。adapter 只接收冻结的 `{questionId, choiceId}`，收不到用户、档案、请求标识。
- requestId 为 1–64 位字母、数字、下划线或连字符。profileId 只参与所有权核对，不发给 adapter。

即使题目是虚构的，真实儿童的答题选择仍可能是儿童相关非公开数据。当前离线测试使用的身份、选项和记录都是合成样例，不能借此批准未来外传真实作答。

## 输出与教学验证

响应只能有 `questionId, answer, correct, explanation` 四个字段。答案使用可信题库的整数除法重新计算；correct 必须与所选选项一致；解释必须与有限目录的标准算式文本逐字一致。错误答案、反转正确性、截断、额外字段、HTML 或任意新文本都拒绝。成功响应是新的冻结对象，adapter 后续修改原始结果不能改变它。

这比一般 LLM JSON schema 更窄：它验证的是有限合成题和确定文本，不声称可以证明开放式模型讲解、语文教学、儿童能力评估或任意生成题的正确性。未来输出必须按文本渲染（例如 textContent）；不得直接将模型文本赋给 innerHTML。已有静态页面用模板 HTML 组织 UI，不等于允许模型 HTML。

## 模拟预算与并发

所有金额字段是非负 safe integer **模拟微单位**，没有真实货币或 token 定价含义。默认总限额 1000、每次预留 100、成功结算 60。它们不是人民币、美元或实际供应商费用估算。

1. 先完成认证、所有权、严格输入校验。
2. 相同 userId + requestId 的相同输入返回同一个 Promise（包括已完成/已失败请求），不再次调用、不双扣；输入变更则冲突拒绝。授权仍在幂等命中之前重新检查。
3. 在第一个异步点之前同步预留最坏成本。限额覆盖所有用户/档案共享的已结算与进行中预留，不能通过切换档案并发绕过。
4. 成功校验输出后结算固定模拟成本，释放余量。
5. 异常、输出校验失败、超时或发起后的取消均保守结算全部预留，不自动重试。发起前已取消则不预留、不扣费。
6. 向 adapter 提供取消信号，但取消并不保证下游工作已经停止。超时后的迟到结果不会覆盖账本或变成成功答案。错误内容被替换为有限错误码，不回传可能携带私密内容的 adapter 异常原文。

内存账本不耐久；重启会清空预算和幂等记录，多进程实例互不共享，幂等表最多保留 maxRequests 个请求（默认 1000），达到容量后拒绝新请求而不驱逐旧键；并发最多 maxInflight（默认 10），不是按时间窗口限流。尚无过期/持久归档管理，也不含日/月预算重置。JavaScript 定时器不能终止阻塞事件循环的同步 adapter。这些都是未解决的生产条件，不应将此程序暴露给公网。

## 当前静态端隐私边界审查

本轮源代码检查：现有 `dist/app.js`/`dist/model.js` 通过 localStorage 在当前浏览器保留记录，页面明确提示不跨设备同步，档案不是账号，同一浏览器可切换查看。题文、选项、提示等动态文本进入模板前使用 HTML 转义；这是现有有界题库场景的代码检查，不是完整 XSS 渗透测试。另已检查新增 `loop-ui.js` 使用统一 esc 函数转义题文、选择和解释，`loop-model.js` 没有网络调用。新增闭环的页面交互由其独立测试覆盖，本模块交叉测试只核对题库和答案，不冒充端到端验证。

本轮检查的原有应用代码没有模型网络请求。静态资源访问仍可使托管服务看到普通访问日志，不能宣传“绝不产生任何网络通信”或“已经实现了应用级身份隔离”。站点托管仍保持仅所有者可访问，但这不能代替未来模型后端逐请求鉴权。本机存储未加密；共享设备上的其他使用者和具有相应权限的软件可访问，清除浏览器数据会丢失记录。静态页面标题中的“私密体验”不构成隐私保证。避免输入或导入真实身份信息；当前只做合成内容与模拟流程。

## 允许真实模型前必须另行完成

- 获得明确的数据共享批准：具体发送哪些数据、哪个服务商、用途、保留/删除规则；尤其不能默认发送儿童记录、题目照片、声音或历史表现。
- 实现真实会话认证、请求防伪和服务端 profile 所有权查询；不要相信浏览器提供的 authenticated 标志。
- 密钥只在服务器秘密存储中管理，绝不能进入 dist、localStorage、源码、日志或客户端请求。当前阶段不需要也不索要 key。
- 明确供应商、模型、价格、账户支出上限及调用授权，验证 token/输出上界和最坏费用。使用事务型持久账本做原子预算预留与幂等，支持多进程、重启恢复、超时不确定结算及供应商账单核对。
- 加入服务端限流、请求体大小和输出 token 限制、日志脱敏、数据最小化、保留期限与删除机制；测试代理超时、客户端断线、供应商重复响应和进程崩溃。
- 独立验证部署配置、鉴权和网络边界；默认关闭真实模型，任何不可确定状态 fail closed，不自动切换收费模型。

**不能声称：** 已接入真实 DeepSeek、已经部署安全后端、已经建立真实身份隔离、已保护生产费用、取得儿童数据外传授权，或通过这些离线测试即可上线。
