# 本机合成自测：固定入口（2026-11-17）

`npm run dev` 现在启动现有学习闭环的家长自测入口。需要 Node.js 22.13+，无需新增依赖。

- 默认地址为 http://127.0.0.1:4040 ，服务始终仅绑定回环地址。
- 保持终端开启。在同一浏览器使用同一地址，原来保存于该 origin 的合成记录才可继续访问。
- 自选端口：`npm run dev -- --port 4041`；临时隔离测试：`npm run dev -- --port 0`。
- 端口占用时明确报错退出，不静默切换，不关闭其他进程，不清除记录。
- 不保证浏览器存储永久可用；清除浏览器数据、私密浏览、换浏览器/设备仍可能看不到记录。不同 localhost/127.0.0.1 或端口不是同一存储空间。
- 旧随机端口记录不会自动搬到 4040。需要旧记录时用旧端口启动，并用原浏览器访问；新包不会扫描、复制或上传旧数据。

仅成年人使用合成数据，不输入/导入儿童真实资料。同一浏览器使用者能查看记录，A/B 分组不是身份验证。固定端口不是账户、隐私锁或云备份。未改变存储格式，未增加持久化或自动迁移。

测试：核心 390/390。新增覆盖默认/自选/临时端口、非法参数、端口占用、关闭后原端口重启及 npm 启动入口。验证的是服务 origin 可重复，不等同于新做了浏览器存储跨重启验收；上轮浏览器记录刷新与档案隔离验收仍见 BROWSER_QA_20261116.md。

未部署或改变两个既有 Sites。成人材料审查站与本机学习流程仍是不同产品范围。
