# 下一步支持已接入现有小步学习流程

本轮不是新增独立审查台。`dist/loop-ui.js` 在真实运行对象的完成页和家长小结中调用 `support-next-step.js`，直接展示当前运行的证据和下一步支持。

- 同类题或复习题仍有困难：先检查过程，可展开当前学科两步示范，再由家长决定是否重新练习。
- 引导后复习正确：明确这是有帮助的原题作答，不能当作独立掌握。
- 同类题当场正确：建议查看现有复习安排；提醒固定题可能以前见过。
- 复习首次正确：不把提前复习或重复固定题错误解读为延迟保留的证明。

支持卡是只读投影，不改作答、错题、复习到期日、存储格式和已有档案隔离。没有新增掌握评分、自动排期、API、上传或模型诊断。1/3 天原有模拟排期未改变，不是本轮提出的教学最优间隔。

## 仅供家长合成自测的本机入口

Node.js 22.13+，无需安装新依赖：

```sh
node dev/parent-flow-preview.js
```

浏览器打开终端打印的回环地址，进入“小步引导”数学/语文/英语中的任一科。选错一题→完成两步提示→原题再试→同类题→完成页支持卡→家长小结→复习安排。全部用固定示例选择，不输入真实儿童资料。

该入口仅绑定 127.0.0.1，校验 Host，禁止 POST、外部网络、麦克风、摄像头、媒体及上传。不会部署 Site，也没有生产登录。测试首页明确是家长自测，隐藏了旧页面关于线上账号私密入口的错误说明。记录仍是当前临时地址的浏览器本地数据，随机端口重启后不保证恢复。此入口视频不可用；原视频素材和原视频功能未删除或改写。
