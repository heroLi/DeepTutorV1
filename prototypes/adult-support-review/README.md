# 成人学习支持方案审查台

本地合成数据原型，帮助家长审查教学材料和下一步支持方案，不是儿童使用的学习系统，也不是已接通 AI 的产品。

## 本轮增加

- 六类固定情境：新概念、提示后正确、重复原题、当场独立、延后新情境、改变分组后出错。
- 分开显示“已有证据”和“尚不能断定”，避免把提示后答对当作独立掌握。
- 人工比较示范、单条提示、无提示新题、延后核查、对照讲解和少量混合复习。
- 增加“演练下一次观察”，从示范、提示、新题独立到延后核查，或转回困难情境；都是人工合成分支，不是预测或真实学习记录。
- 支持方案与原讲解评分各自保存、重评替换、确认清空、独立导出；切换工作流保留各自草稿。

## 运行

需要 Node.js 22.13 或更新版本，无第三方依赖，无需 npm install。

```sh
cd adult-support-review-20261116
npm test
npm run dev
```

浏览器打开终端显示的 http://127.0.0.1:3000/ 。这是本机入口，不是手机可访问的在线网站。关闭服务按 Ctrl+C。

## 数据与教学边界

只使用人工编写的合成题目、表现和参考方案；没有姓名、真实作答、儿童档案、录音、上传、模型调用或付费。所有选择只保存在本页内存，刷新和关闭即消失。下载报告仅含已保存的选择，草稿不导出；没有恢复导入或跨设备同步。

方法方向参考 [IES/WWC 原始指南](https://ies.ed.gov/ncee/WWC/PracticeGuide/1) 的间隔学习、示范与练习交替、主动回忆和解释性追问。六类情境及动作匹配是本项目设计假设，不是该指南验证的个体诊断算法。没有统一掌握分数或固定复习天数，未验证能改善学习成绩，也未核对具体上海教材。
