# 孩子独立练习页

本批只覆盖离线平均分规则示例，不是三科课程，也不调用真实AI。先由家长核对，再把独立练习页交给孩子。

## 使用

1. 家长选择档案，生成未经编辑的平均分示例，核对题目、步骤与练习答案。
2. 勾选确认，点击“开始离线分步学习”。既有已完成视频的规则示例也可进入。
3. 点击“打开孩子练习页面”，再把屏幕交给孩子。孩子页不读取完整讲解稿、标准答案或预先准备的下一题。
4. 孩子先作答，也可点“我还不会”。之后可选最多三层提示，逐步再试。
5. 首题正确后点击“换一道新题再试试”。新题与首题、旧版公开练习题的数字和答案不同，并排除本档案已经分配过的练习题与已做对的旧版练习题。
6. 新题完成后查看小记。返回同一道家长题目再打开，会继续原会话，不重复累计证据。

本页始终注明“本题教材对应关系待核对”。即使家长已配置教材，也不能把规则题自动称为教材同步题。编辑过的示例、模型题和未支持题型会明确拒绝进入，避免套用错误规则。

## 证据含义

首题可能已在家长页面看过讲解，因此不计独立学习证据。只有新的迁移题首次作答正确、未使用提示、且未被其他练习随后暴露，才记录一次独立应用线索。先答错、先求助、看提示后改对都保留过程，但不改写首次作答结果。

同一道题重复打开、刷新或重交不会变成新的独立证据；一次独立答对也不等于掌握。本批没有新增按日期安排的复习、能力等级或三科综合评分。

可用新题池有限。没有未练过的支持题时明确停止，不用重复题冒充新题。删除题目会连同这道题的练习会话、作答与请求记录一起删除；删除历史意味着系统不再保留被删除的题目记忆。

新证据保存在独立会话表中，可重新打开该会话查看。它不混入旧版复习天数；原“导出旧版复习记录”仅导出旧记录，尚无覆盖全部新证据的导出工具。

## 状态与故障

服务端用SQLite写事务、递增revision和action_id处理双击、重复请求与多页竞争。同一动作重试不新增作答；不同动作使用过时revision时返回409。客户端随后只重新读取进度，不自动重交孩子刚输入的答案。

如果网络响应不确定，保留同一个动作编号和完全相同的请求体用于重试。刷新与浏览器返回只读取服务端状态，不重放作答。已完成题不允许继续累计次数。课题删除后会话读取返回404。

孩子API采用公开字段白名单，不返回answer、plan、scenes或预留题目的数字。标准答案仅由服务端整数规则计算；提示沿用离线TutorProvider。系统不上传姓名、学校、声音、照片或学习记录。

这仍是本机家庭原型，档案不是登录账号隔离。真实浏览器、手机布局、辅助技术和儿童实用测试尚未完成；Node脚本状态测试不替代浏览器验收。所有本批自动化测试均使用合成题和临时数据库，并禁止网络外连。
