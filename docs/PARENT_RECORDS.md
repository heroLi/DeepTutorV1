# 家长查看与导出孩子练习小记

家长页面新增“孩子练习小记”，把孩子独立练习页的会话集中列出。它不新增题型、评分或复习安排，不调用真实模型。

## 查看和继续

选择当前档案后，小记展示已完成和进行中的会话，以及首题、新题的首次作答结果、尝试次数和提示次数。未完成时可点“继续练习”，完成后可重新查看本次小记。这些操作不会重新提交答案或新增学习次数。

首题可能已在家长页看过，因此不计独立证据。新题的“独立应用线索”只保留服务端已经记录、且首次正确、未用提示、仅有一次作答的有效记录。它是一条练习观察，不是能力评级或掌握证明。

仍显示“本题教材对应关系待核对”。教材配置的填写或核验不自动使这道规则题成为同步教材内容。

## 日期的含义

此版本开始记录新会话创建时间、最近一次活动，以及首次和最近作答时间，服务端保存UTC时间，家长页按上海时间显示。重试同一请求、刷新、查看和导出不改变原有日期或计数。

以前保存的记录没有日期时，显示“日期未记录”，导出值为null。即使旧会话后来再次作答，也只记录这次确实发生的活动和最近作答，不补造过去的创建或首次作答时间。

## 导出

点击“导出孩子练习小记”会重新读取当前档案的最新数据，再下载JSON到本机。导出包含会话题目、状态、上述证据和可用日期，不包含标准答案、完整讲解稿、还未展示的新题、原始作答文本、请求重试载荷或另一个档案的数据。

这是新孩子练习页的证据导出。旧版复习记录仍用原来的独立导出按钮，两个文件没有自动合并。没有把数据上传到第三方，也没有替用户保存到云端。

切换档案时立即清空旧显示；多次切换和较晚返回的请求不会覆盖当前档案。导出失败会明确提示重试，不将旧缓存伪装成成功下载。删除题目后重新查看或导出不再包含该题的孩子练习记录。

## 技术与边界

GET /api/practice-records?learner=sister 和 GET /api/practice-records/export?learner=sister 仅作只读查询，另一个档案使用little_sister。两者返回no-store头；导出另设JSON附件响应。字段按白名单生成，损坏或身份不一致的记录返回有限的错误说明，不回显内部数据。

本批自动化测试使用临时数据库和合成题，覆盖档案隔离、未知日期、只读请求、导出更新、删除同步、异常恢复及界面迟到响应。测试环境禁止网络外连。

真实浏览器、手机布局和儿童实用尚未验收；Node状态测试不是浏览器验收。仍仅供本机家庭试用，档案不是独立登录权限。小记不是正式成绩单，也不声称带来提分效果。
