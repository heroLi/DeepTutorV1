## 使用范围

离线学习只读已确认的讲解稿；规则示例支持 2～48 颗糖、2～8 人且可整除。家长仍需按孩子理解程度选择题目。两个档案不是独立权限账号；仅适合本机家庭试用。需要编辑已确认稿或改为视频时新建题目。未公开服务。

## 最小可用预览下一步（尚未执行）

先准备不含 `.env`、`data/`、虚拟环境和缓存的更新代码包供家长下载；由家长在自己的电脑上启动本机版。需要自动同步到用户电脑时另行取得目标和操作许可。助手云端的 `127.0.0.1` 不是用户可访问地址，不能作为分享链接。

离线文本流程需要 Python 3.11+、可写的数据目录及这些已安装的应用包：FastAPI>=0.115,<1，Uvicorn>=0.30,<1，Pydantic>=2.8,<3，HTTPX>=0.27,<1，Pillow>=10.4,<13。SQLite 随 Python，系统需支持 Asia/Shanghai 时区。正常本机浏览器用于打开页面。离线示例不需要 pytest、DeepTutor、模型密钥、edge-tts 或 FFmpeg；这些仅分别用于测试或可选服务/视频功能。不要直接运行会安装全套依赖并检查 FFmpeg 的 start.sh。

在依赖已齐备时，从项目目录运行 `python -m uvicorn app:app --host 127.0.0.1 --port 8765`，在同一电脑打开 `http://127.0.0.1:8765`。选择离线规则示例、由家长确认并使用“开始离线分步学习”。不选择模型或视频功能即可避免此学习流程的外部服务调用。
