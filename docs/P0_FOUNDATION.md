# P0 教材配置与离线辅导接口

本批只建立三科共用的配置与测试基础，不提供三科全套课程、真实 DeepSeek、语音或拍题。

## 家长配置

在“教材与学期”中填写年级、学期、学年，再逐科填写实际书名、出版社、版次、资料来源与当前单元。地区固定上海，学制为五四，小学年级仅1至5。旧档案的年级不再被默认当成已确认。

默认显示“按能力练习 · 教材进度待核对”。书目核对和孩子进度是两个状态：只有主教材标为已核对、证据齐备、进度也经家长确认，才显示“家长已核对教材进度”。这不代表系统已有对应单元题库或官方认证映射。练习册、教师用书不代替主教材。没有内置或猜测单元表。

状态为待核对、已核对、需更新和停用。更改已保存的年级、学期或学年会清空各科当前进度及核验日期，并把已核对教材改为需更新。请保存后重新核对。更换教材书名、出版社、版次、类型或来源也会清空旧核对与进度，保存后需再次确认，避免新书继承旧书状态。保存时配置输入会暂时锁定，避免响应覆盖新输入。切换学科前先保存；同科配置包含修订号，陈旧页面保存返回409而不是覆盖较新的内容。

配置按本机档案保存到SQLite，不包含姓名、学校或班级字段。两个档案并非登录权限隔离。资料来源仅保存文本，不自动读取链接、上传图片或复制教材。

## 接口

- GET /api/curriculum?learner=sister：默认未知年级、空教材及状态；little_sister使用独立记录。
- PUT /api/curriculum?learner=sister：提交config与expected_revision；schema_version为1.0，拒绝额外字段。
- POST /api/tutor/hint：仅允许schema_version、total、groups、hint_level。当前只提供平均分离线提示；缺条件返回needs_clarification，不支持的数值返回unsupported。

TutorProvider有Offline与Fake实现。Fake仅用于注入合成返回和超时，仍标为未验证且需人工核对。返回含提示级别、提示文字、下一问、来源ID、人工核对标记；verified_status由服务端添加，不接受提供方自行声称验证通过。来源offline:division-equal-groups-v1是本地规则编号，不是教材认证。

严格校验空白、截断、额外字段、超长文字、未知来源和错误类型。超时或不合格Fake返回可见的provider_error，绝不伪装成功。所有声明需外发的Provider都会在调用前被阻止，当前没有能被开关打开的远程实现。HTTP接口不接受provider、外发同意、孩子历史或密钥。此限制仅描述新增接口；旧的显式模型/DeepTutor入口仍是原有配置路径，本次未调用或联调它们。

后续离线孩子页已接入该提示接口，独立于家长完整讲解页面；首次作答、提示和新题证据见 CHILD_PRACTICE.md。旧版逐步显示完整讲解仍不能等同于答案隐藏辅导。

## 环境与CI

requirements-offline.txt列出最小离线运行范围。requirements-ci.txt固定Python3.12/Linux的离线测试依赖，包括符合原声明的Pillow12.3.0，不含Edge TTS、SOCKS、OCR、浏览器或真实提供方。它是固定版本清单，不是跨平台带哈希的发布锁文件。

GitHub工作流只做checkout、安装测试依赖、pip check、Python回归、JS状态/语法与Python语法检查，不部署、不使用用户密钥。GitHub Action引用固定提交，checkout不持久化凭据。pytest自动fixture禁止所有测试的外连socket，测试数据均为合成或临时数据库。

本地仍复用已安装Pillow13，不将其测试结果说成Pillow12.3已验收；声明内环境结果以该提交的CI为准。真实浏览器、移动布局、儿童试用、真实模型、视频重渲染仍未验收。
