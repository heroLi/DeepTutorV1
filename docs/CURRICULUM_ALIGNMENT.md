# 上海三科教材同步：核验框架与待补资料

当前完成的是可核验的对应框架，不是三科教材内容已经同步。现有数学平均分、语文反义词和英语 a/an 均保持“通用原创练习”标签。不能根据知识点看起来相近，就声称对应某版教材、某年级或某单元。

## 分开核对三件事

1. 家长确认实际用书：每个档案的年级、学年、上下学期，以及语文、数学、英语的书名、出版社、版次和当前单元。
2. 核对教材目录：上海五四学制下，具体版本和单元必须有可追溯来源、核验状态与日期；配套练习、教师用书不能替代学生主教材。
3. 审核原创练习对应：练习与已核验单元的教学目标对应，需要单独的审查依据和当前内容指纹。目录核验不等于练习适配已经核验，改动练习后旧审核不能自动继续有效。

家长填写的“已核对”仅表示用书资料和进度由家长确认，不授予系统内容的已验证状态。浏览器提交的教材或来源信息不会触发外部访问，也不能写入服务器的已核验目录。教材、年级、学期变化时必须重新核对。

## 接口兼容与可追溯性

旧接口字段 `subjects.*.textbook_aligned` 为兼容保留，仅表示家长元数据和进度已确认，不表示系统内容对应。新增 `parent_metadata_confirmed` 明确该含义；系统是否有已核验映射以 `content_aligned` 和 `alignment.subjects` 的状态及原因判断。即使有一条已核验映射，也只表示当前单元有对应的原创练习，不表示完整同步课程。

已核验映射提供练习ID、单元ID、来源引用、内容指纹、审查日期和说明供复查，不返回标准答案或课文内容。教材目录仅通过经审查的代码条目维护，没有客户端写入或外部网址抓取接口。

## 当前可见功能

家长页面展示三科各自的同步准备状态、缺失条件与参考来源。生产目录暂为空，没有伪造的单元选项或已同步课程。后端已为版本、单元、来源和原创练习映射提供校验接口；待官方证据与实际教材都齐全后，再录入经过审核的目录并开放实际选择流程。

当前通用练习仍可继续使用，学习记录不会被追溯改写为教材同步证据。同步准备状态也不证明教学效果或孩子已掌握。

## 下一步需要的最小资料

请分别确认两个档案的年级、上下学期，以及三科实际教材的封面书名、版权页版次和目录。只需教材信息；无需孩子姓名、学校、班级、证件或成绩。分享书页照片时可遮住手写姓名等个人信息。仅提取必要书目信息和目录结构，不复制受版权保护的课文、整页题目或答案。

## 检查与边界

自动化测试使用合成教材与临时目录，覆盖来源链、版本和学期匹配、单元与原创内容指纹、未审核或失效数据拒绝、档案隔离、迟到响应以及三科原有练习回归。合成测试条目不出现在生产目录。

没有真实模型、教材内容爬取、儿童资料外传或部署。真实浏览器仍因既有 socket 限制未验收，脚本状态检查不能代替手机、桌面实际使用。
