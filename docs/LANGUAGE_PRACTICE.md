# 语文和英语离线练习

本版各增加一个小范围原创通用知识点：语文在具体情境中找反义词；英语在明确发音的常用单数名词前选择 a 或 an。它们不是某册教材的单元表，不声称对应孩子实际年级、上海最新教材进度或完整课程。

## 家长与孩子的流程

家长选择当前档案、学科并确认了解练习范围，再打开孩子练习页。先独立作答，也可以选择“我还不会”；尝试之后可逐层打开最多三条提示。首题完成后换一道不同的新题。

首题不计独立证据。新题的第一次作答正确且未用提示时，才可能保留一次独立应用线索；答错后改对、看过提示再答对都如实记录，不称为掌握。每科目前只有 8 道题，最多安排 4 组初题与迁移题。创建一组即预留两题，即使尚未作答或后来删除，也不再把它们包装成未见过的新题。没有未安排新题时会明确提示，可继续已有会话；这不等于孩子已经完成全部题目或掌握知识点。

家长可在原有“孩子练习小记”查看语文、数学和英语的练习过程，并按当前档案导出 JSON。语文、英语记录提供删除入口，需要家长确认。删除会移除本次会话、作答和操作响应；仍保留固定档案对应的已用题编号，以及开始请求的随机编号、学科和随机会话编号，以防旧请求重新创建已删练习或重复题被计作新题。这些最小标记不保存答案、日期或分数。题库用尽后会如实提示，不自动重置为新题。

档案只是本机家庭数据分类，不是独立登录权限。

## 内容与判题边界

语文题限定具体情境和作答范围，避免把开放式表达误判为唯一答案。英语练习按单词开头的读音选择冠词，不把首字母规则宣称为普遍规则；本版没有播放发音、录音或语音识别，也不测试口语能力。

题目、答案和提示来自本机固定原创题库，不调用真实模型。不支持任意语文作文、阅读理解、翻译或自由问答。服务端只向孩子页面返回当前题目和已经请求的提示，不预载标准答案或下一题。

## 验证范围

自动化检查使用合成档案和临时数据库，覆盖两科完整作答流程、渐进提示、首次证据、请求重试、档案隔离、只读导出和数学回归。Node 检查执行真实页面脚本的轻量 DOM 状态，不等同于浏览器布局验收。

当前云端真实 Chromium 曾因 `socket() failed: Operation not permitted` 无法启动，未绕过限制。因此桌面/手机真实点击、下载、布局、辅助功能和儿童实用仍未验收。运行方式和依赖不变；无需新增模型密钥、付费服务或媒体依赖。
